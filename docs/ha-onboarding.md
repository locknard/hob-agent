# Home Assistant 接入流程（Phase 0）

## 产品承诺

第一次接入的目标不是“让 agent 控制家”，而是让用户确认它能准确地
**读懂家**。默认模式始终为只读；任何写入能力都需要在独立步骤中显式开启。

## 0. 欢迎：说明边界，而非索要 token

首屏用三句话解释：

1. 先读取设备、房间和当前状态，整理成可编辑的家庭地图。
2. 不会创建、修改或执行任何 HA 自动化，也不会控制设备。
3. 数据默认留在本机；访问 token 仅保存在本地安全存储中，绝不发送给模型。

主按钮为“连接我的 Home Assistant”，次按钮为“先看示例”。不要把 token
输入框放在欢迎页。

## 1. 定位实例：用户确认优先

优先展示用户输入的 URL；在用户点击“在局域网中查找”后才运行 mDNS/局域网
发现，绝不默认扫描网络。发现多个实例时显示实例名、地址和 HTTPS 状态，由用户
选择。自签名证书必须展示指纹并要求一次性确认，不能静默降级 TLS 校验。

代码入口 `probeHomeAssistantEndpoint` 只读取 WebSocket 的初始 `auth_required`，返回版本
与延迟并立即关闭；默认 5 秒超时，且在这一阶段绝不发送 token 或任何 HA 命令。

## 2. 授权：最小权限、可撤销

界面分步展示 HA 创建长期访问 token 的说明，并提示用户给 token 命名为
`hob-agent-readonly`。粘贴后立即执行只读预检；输入框不回显、不进日志、不进入
agent 上下文。失败时只说明可操作的原因（URL 不可达、证书、认证失败、版本不支持），
不显示 token 或原始响应。

## 3. 预检：把信任建立在可见证据上

验证成功后展示以下“连接报告”，用户点击“导入家庭地图”才继续：

| 项目 | 展示内容 |
| --- | --- |
| 可达性 | 连接地址、TLS 状态、HA 版本、最近延迟 |
| 读取范围 | 实体、设备、区域数量；不展示设备名称，除非用户展开 |
| 能力 | 当前仅“读取状态与解释”；“控制设备”和“写入自动化”明确标记为关闭 |
| 隐私 | token 本地保存、原始实体名只用于本地世界模型、不会作为模型指令 |
| 退出 | 随时“移除连接并删除本地索引”；不触碰 HA 原有配置 |

预检只调用 WebSocket 认证、`get_states` 和 registry 读取；不得调用
`call_service`、创建自动化或写入任何 HA 数据。

## 4. Bootstrap 仪式：从清单到“家的地图”

导入后不要给用户丢一张实体表。以 2–3 分钟的对话式校对完成：

1. 先展示七个以内的房间卡片与每个房间的设备数量。
2. 对置信度低的归属逐项提问，例如“这个 `switch` 实际控制哪里？”。
3. 生成可编辑 Markdown 文件，并把每项推断标记为“来自 HA”或“你的确认”。
4. 最后给出一张只读的“现在的家”摘要和可撤销的导入记录。

任何模型生成的命名或推断均是建议，不能覆盖 HA 的原始名称，也不能当作自动化
事实。用户修改文件后，下一次会话必须以该文件为准。

## 5. 就绪页：先获得解释能力

完成后只提供两个安全入口：

- “家里现在怎么样？”：读取快照与事件摘要。
- “为什么这个设备刚刚变化？”：展示可追溯的 HA 事件链。

产品在此阶段不显示“自动化控制台”。在积累足够观察证据后，才以提案形式邀请用户
开启“生成自动化建议”；建议仍须提供 dry-run、diff、批准和一键撤销。

## 6. 后续权限升级：按能力分级，不是一键全权

| 阶段 | 默认权限 | 用户可获得的价值 | 升级门槛 |
| --- | --- | --- | --- |
| 只读连接 | 状态、registry、事件订阅 | 家庭地图与解释 | 完成预检 |
| 建议 | 只读分析 + 本地提案 | 发现可自动化的习惯 | 用户主动开启建议 |
| 写入制品 | 经审批写入 HA automation | 合并已审阅的提案 | 每项提案确认、审计、可回滚 |
| 高风险动作 | 默认禁止 | 无 | 单独设计与安全审查后才考虑 |

门锁解锁、安防解除和加热设备等高风险动作不属于 Phase 0，也不能因为用户开启写入
自动化而默认获得权限。

## 异常与恢复

- token 失效：暂停同步并提示重新授权；绝不回退到匿名或环境变量中的其他凭据。
- HA 离线：保留最后一次快照并标明时间；不把“桥离线”误报为“所有设备离线”。
- 导入中断：保存进度，可从安全检查点继续；不产生半写入 HA 状态。
- 删除连接：默认删除本地索引与 token，保留用户明确选择保留的 `home/` 知识文件。
